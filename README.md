# CIL-MUM-Civic-Budget-Accountability

Prototype tools for **Claude Impact Lab Mumbai: Civic Budget & Accountability**.

| What | Where |
|---|---|
| Idea catalogue for the challenge | [`IDEAS.md`](IDEAS.md) |
| Tender-based expense monitoring ideas, data sources, method | [`docs/EXPENSE_MONITORING.md`](docs/EXPENSE_MONITORING.md) |
| Website (GitHub Pages): analytics for Mumbai and MMR, 3D digital twin | [`docs/`](docs/) |
| Synthetic sample-data generator | [`scripts/generate_sample_data.py`](scripts/generate_sample_data.py) |

## Website

The site is static (no build step) and lives in `docs/`.

```bash
cd docs && python3 -m http.server 8000
```

Open `http://localhost:8000`. Pages: `index.html`, `analytics.html`, `twin/`.

### Data honesty

- `docs/data/organisations.json` is a **real, dated snapshot** of public tender counts from the Maharashtra eProcurement organisation list.
- `docs/data/tenders.sample.json` is **synthetic**, generated by `scripts/generate_sample_data.py`. It demonstrates the indicators and says nothing about real tenders or companies.
- Replace the sample file with verified data in the same schema (set `"synthetic": false`) to make the dashboard real.

### Deploying to GitHub Pages

`.github/workflows/pages.yml` deploys `docs/` on every push to `main`. One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
