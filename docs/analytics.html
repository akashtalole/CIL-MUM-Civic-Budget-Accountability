4. Tenders worth a closer look

Rules applied: single bidder, award within 97–100% of estimate, two or more extensions. Tenders with more flags are listed first.

Method

Indicators

Single-bidder share, award/estimate ratio, extensions, contractor concentration (top shares and Herfindahl–Hirschman Index), monthly value and timing. Definitions and caveats are in EXPENSE_MONITORING.md.

Plugging in real data

Replace data/tenders.sample.json with verified records using the same schema (tender_id, organisation, org_short, city, category, estimated_cost_cr, awarded_value_cr, bidders[], awarded_to, published_on, extensions, status) and set "synthetic": false. The banner and tags update automatically.
